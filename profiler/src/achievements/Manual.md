# Read the manual

Tracy ships with a built-in user manual that describes all of its features. You can open it by clicking the * Manual* icon in the top toolbar of the profiler window.

It's an alternative to external documentation — always available offline, and it covers everything from basic instrumentation to advanced sampling and memory profiling.

> [!TIP]
> **Tip**
>
> When you're unsure how to do something, the manual is the quickest way to find out. Keep it handy while you explore.
