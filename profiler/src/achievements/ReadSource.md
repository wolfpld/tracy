# Read the source

Tracy copies your source files into the trace as it profiles, so you can read the exact code that ran, even after you have edited or moved the files on disk. Right-click the file location shown anywhere in the profiler, for example the `Location` line of the [Zone info window](#zoneinfo), and the [Source view](#sourceview) opens with that line highlighted.

Right-click your zone's file location and start reading. Where a `Source` button is shown instead, it does the same. Try it out!
