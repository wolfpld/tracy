# Find some zones

To find a zone, open the Find zone window with the * Find* button on the top bar and type in the zone name — in most cases the function name in the code.

1. If several zones share the name, a list of matches is shown. Select the one you're looking for.
2. The window shows a histogram of execution times, along with statistics such as total time, mean, and median.
3. Drag a range on the histogram to filter the zone list below to just the entries within that range.
4. Pick one of the zone groupings to highlight that group's time on the histogram.

You can also jump straight to a zone from the Statistics window: clicking an entry there opens Find zone as if you had searched for it.
